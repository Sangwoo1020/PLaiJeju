# 사용자 매뉴얼

프로그래밍을 몰라도 쓸 수 있도록 만든 관광 낙수 진단 도구입니다. "외국인·크루즈 관광객이 늘어난 만큼 그 돈이 우리 동네에 떨어지고 있는가"를 말로 물어보세요.

프로그램에는 실제 공개 데이터(제주관광공사 읍면동별 관광객 소비·방문객 2026년 9월까지, 관광객 입도통계, 크루즈 입항 실적, 소상공인 상가 매장 수)가 들어 있어 **켜자마자 지표 8종을 실제 값으로 볼 수 있습니다.** 센터에서 내려받은 파일을 넣으면 그 데이터를 먼저 쓰고, 저녁·밤 소비, 쓰레기 부담, 동네 식당 체감, 도민 가게 몫까지 볼 수 있습니다.

## 시작하기

센터 담당자가 설치해 둔 PC 에서 `run.bat` 을 실행하면 브라우저에 화면이 열립니다. 명령창은 닫지 말고 그대로 두세요.

첫 화면에서 섬의 지명(제주시, 한라산, 성산일출봉 등)이나 땅을 누르면 그곳으로 당겨 볼 수 있습니다. 지명을 누르면 왼쪽에 그 동네 카드가 떠서 외국인 관광객 소비·방문객의 전년 대비 변화, 낙수 지수, 가게당 관광객 소비, 최근 2년 소비 흐름을 관광공사 공개 데이터로 보여 줍니다. 카드의 **진단 화면에서 이 동네 보기** 를 누르면 같은 조건으로 진단 화면이 열리고 그 동네가 선택됩니다. 제주시·서귀포·중문은 실제 건물까지 보입니다. 위쪽의 **섬 전체 보기** 나 Esc 로 돌아옵니다. 첫 화면에서 **진단 화면으로** 를 누르면 진단 화면으로 넘어가며, 처음에는 **주의 지역 종합** 이 보입니다. 진단 화면에서 왼쪽 위 제목 **제주 관광 낙수 진단** 을 누르면 데이터는 그대로 둔 채 메인 화면으로 돌아옵니다. 센터 데이터는 **센터 CSV 불러오기** 를 눌러 넣습니다. 왼쪽 데이터 창의 **가상 데이터 불러오기** 는 센터 CSV 가 없을 때 12종을 모두 보여 주는 시연용이며, 이때 수치는 실제 통계가 아니고 위쪽에 '가상 데이터' 표시가 붙습니다.

**관광공사 공개 데이터로 볼 때 다른 점**: 지역은 읍면동(행정동 43곳) 단위이고, 이용자는 도민·내국인 관광객·외국인 관광객 세 가지뿐입니다(중국·일본 등 국적별로는 볼 수 없습니다). 업종은 소매·숙박·음식점·여가·기타서비스 다섯 가지입니다. 대신 낙수 지수를 권역이 아니라 읍면동 단위로 볼 수 있습니다.

전년 같은 달과 비교하므로, **보고 싶은 달과 1년 전 같은 달을 함께** 받아야 합니다. 예를 들어 2026년 10월을 보려면 2026년 10월과 2025년 10월 파일이 필요합니다. 카드 데이터는 2025년 5월, 외국인 유동인구는 2025년 4월 이후부터 이 형식으로 제공됩니다. 크루즈 기항 효과는 여러 달을 모아 계산하므로 카드 데이터가 4개월 이상 있어야 합니다.

### 크루즈 입항 실적을 직접 넣을 때

2025년 6월 이후의 입항 실적은 아래 컬럼의 CSV(UTF-8)로 만들어 넣습니다. 제주특별자치도 누리집의 '크루즈선 입항실적' 표(입항일시, 선명, 항로, 관광객수, 입항항)를 달별로 더하면 됩니다. 센터 밖에서는 `python tools/fetch_cruise_arrivals.py` 가 같은 파일을 만들어 줍니다.

```
month,calls,passengers,china_calls,china_passengers,jeju_port_calls,gangjeong_calls
202506,30,72000,20,55000,12,18
```

같은 달이 이미 들어 있으면 새 파일의 값으로 바뀝니다.

### 입도통계를 직접 넣을 때

2026년 9월 이후 달은 제주특별자치도관광협회 누리집 '월별통계'(확정치)를 아래 컬럼의 CSV(UTF-8)로 만들어 넣습니다. 국적마다 한 줄이고 내국인은 country 를 내국인, segment 를 내국인관광객으로 적습니다. segment 는 카드 이용자구분(중국, 일본, 동남아, 기타외국)에 맞춰 적습니다. 동남아는 싱가포르·말레이시아·인도네시아·베트남·태국이고, 홍콩·대만·미국 등은 기타외국입니다. 한국 입국자(korea_arrivals)는 비워 두어도 됩니다. 센터 밖에서는 `python tools/fetch_foreign_arrivals.py` 가 협회에 게시된 달까지 같은 파일을 만들어 줍니다.

```
month,country,segment,jeju_arrivals,korea_arrivals
202609,중국,중국,175000,
202609,대만,기타외국,30000,
202609,내국인,내국인관광객,1000000,
```

### 처음 넣을 때 점검하기

실제 센터 CSV 로는 개발 중에 시험하지 못했습니다. 처음 내려받은 파일은 프로그램 폴더의 명령창에서 아래처럼 점검해 주세요. 파일마다 어떤 데이터인지, 숫자와 코드값이 지표가 기대하는 형식인지, 데이터끼리 이어지는지, 지표 12종이 계산되는지를 `[확인]`, `[주의]`, `[경고]`, `[없음]` 으로 보여줍니다. 결과는 화면에만 나오고 원본 행이나 금액은 나오지 않습니다.

```
.venv\Scripts\python tools\center_check.py 내려받은CSV폴더
```

## 2단계. 파일 넣기

왼쪽의 **CSV 불러오기** 에 파일을 끌어다 놓으세요. 여러 개를 한 번에 넣어도 됩니다. 어떤 데이터인지는 자동으로 알아보고, 같은 파일을 두 번 넣어도 한 번만 계산합니다. 엑셀에서 저장한 CSV(CP949)도 UTF-8 과 똑같이 읽습니다.

## 3단계. 물어보기

왼쪽 아래 질문창에 평소 말투로 적고 **물어보기** 를 누르세요.

- 외국인 관광객이 늘었는데 돈은 어느 동네에 떨어지나요?
- 크루즈가 많이 온 달에 음식점 매출도 늘었나요?
- 내국인이 줄어든 자리를 외국인이 메우고 있나요?
- 우도와 성산은 사람만 늘고 쓰레기만 쌓이나요?
- 중국 관광객의 객단가는 작년보다 어떤가요?

답변이 끝나면 섬과 오른쪽 목록이 그 내용으로 바뀝니다. 데이터가 부족하면 어떤 데이터의 몇 월을 받아 오면 되는지 알려줍니다.

### 이어서 묻기와 자동 브리핑

- **이어서 묻기**: 답을 받은 뒤 "그럼 음식점만 보면?", "작년 이맘때랑 비교하면?"처럼 이어서 물으면 앞선 질문의 동네·달·관광객을 이어받아 답합니다. 답 아래 **새 대화** 를 누르면 처음부터 다시 묻습니다.
- **이번 달 자동 브리핑**: 질문창 위의 보라색 단추입니다. 질문하지 않아도 Agent 가 여러 지표로 문제 동네를 스스로 찾고, 많이 걸린 동네의 추이와 요약을 확인해 '주의 동네 3곳, 근거 수치, 다음에 확인할 것'을 씁니다. 보고서도 함께 받을 수 있습니다.
- **진행 단계 읽기**: 답 위에 Agent 가 한 일이 차례로 보입니다. '계획'은 Agent 가 정한 할 일, '실행'은 계산한 것, '검증'은 답의 수치를 계산 결과와 대조한 결과입니다. 근거를 찾지 못한 수치가 있으면 Agent 에게 되돌려 한 번 고쳐 쓰게 하고, 그래도 남으면 답 아래에 표시합니다.

## 4단계. 화면에서 직접 보기

아래쪽 문장의 밑줄 친 부분을 누르면 월, 지역 단위, 업종, 이용자 구분을 바꿀 수 있습니다. 이용자 구분은 외국인 전체, 중국, 일본, 동남아, 기타 외국인, 내국인 관광객, 도민 중에서 고릅니다.

- **섬**: 지역마다 기둥이 솟고 이름과 값이 적힌 라벨이 붙습니다. 기둥이 높을수록 값이 크고, 진한 파랑은 늘어난(평균보다 높은) 곳, 하늘색은 줄어든(평균보다 낮은) 곳입니다. 낙수 지수에서는 낙수 지수가 높은 곳에 동전이 떨어지고, 크루즈 기항 효과에서는 제주항·강정항에서 효과가 큰 곳으로 선이 이어집니다. 저녁·밤 소비에서는 하늘이 해 질 녘으로 바뀌고 기둥 머리에 불이 켜집니다.
- **화면 전환**: 지표를 바꾸면 카메라가 그 지표의 구도로 옮겨 가고, 기둥이 다시 솟습니다. 지역(기둥, 라벨, 목록)을 누르면 그 동네로 날아가 확대하고, 다시 누르거나 빈 곳을 누르면 돌아옵니다.
- **도시 모드**: 제주시·서귀포·중문 도심의 동네를 고르거나 휠로 크게 확대하면, 나무 같은 소품이 사라지고 실제 건물과 도로가 3D 로 보입니다. 고른 동네의 건물은 지표 색으로 물듭니다. 주제와 관련된 곳은 색과 이름표로 강조됩니다. 남색은 관광 소비가 몰리는 곳(드림타워, 신라면세점, 누웨마루거리, 중문 리조트), 파랑은 관문(공항, 제주항·강정항 크루즈터미널. 강정항 건물은 위치만 맞춘 단순 모형), 청록은 도민 상권(동문재래시장, 칠성로, 서귀포매일올레시장, 오일시장)입니다. 이름표를 누르면 그곳으로 날아가 왜 봐야 하는지 설명이 펼쳐집니다. 건물 높이 일부는 추정값이고, 동네 구분은 가까운 동 중심 기준이라 대략입니다.
- **조작**: 섬을 끌면 돌아가고, 휠로 확대합니다. 지명을 누르거나 빈 땅을 두 번 누르면 그곳으로 당겨 봅니다. 직접 움직이면 그때부터는 카메라가 따라 움직이지 않습니다.
- **주의 지역**: 지표마다 문제 쪽으로 가장 치우친 곳 최대 3곳을 산호색으로 강조합니다. 오른쪽 위 카드에 무엇이 문제인지 한 줄로 적고, 목록에는 '주의' 표시를, 섬에는 느낌표 라벨과 땅에서 퍼지는 고리를 붙입니다. 증감·지수는 기준선(0% 또는 제주 평균 1)보다 나쁜 곳만, 비중·값은 가장 나쁜 곳을 고르며, 표본이 적은 곳은 고르지 않습니다. 그래서 목록 맨 위가 주의 지역이 아닐 수 있습니다.
- **주의 지역 종합**: 지표 메뉴 맨 위 '한눈에'에 있습니다. 동네마다 문제 쪽에 든 지표 수를 세어 기둥 높이와 산호색 농도로 보여 주고, 여러 지표에서 함께 걸린 동네 3곳을 위쪽 카드에 둡니다. 목록에는 어느 지표에서 걸렸는지 적힙니다. 지표마다 데이터와 계산 단위가 달라, 개수는 어디부터 들여다볼지 정하는 길잡이입니다. 권역·시 단위로만 나오는 지표는 개수에 넣지 않고 아래에 따로 적습니다.
- **알고리즘 분석**: 지표 메뉴 아래 묶음에 기대 대비 실제, 크루즈 보정, 동네 유형이 있습니다. 관광공사 공개 데이터로 읍면동 단위로 계산하며, 이용자는 외국인 또는 내국인 관광객만 볼 수 있습니다. 동네 유형은 섬 위 기둥과 목록을 유형별 색으로 칠합니다.
- **동네 진단 카드**: 목록이나 섬에서 동네를 누르면 왼쪽에 카드가 열립니다. 그 동네의 지표별 값과, 막대 위 점으로 제주 동네 사이의 위치를 보여 줍니다. 세로선은 기준선(평균 1 또는 0%)입니다. 문제 쪽에 든 지표는 빨갛게 맨 위에 모이고, 관광공사 공개 데이터가 있으면 최근 2년 외국인 소비 흐름도 그립니다. 지표를 누르면 오른쪽 목록이 그 지표로 바뀝니다. **이 동네 Agent에게 묻기** 를 누르면 문제로 나온 지표의 원인을 묻는 질문이 바로 보내집니다.
- **두 동네 비교**: 카드의 **비교에 추가** 를 누른 뒤 다른 동네를 누르면, 두 동네의 지표를 나란히 놓고 막대 위에 두 점으로 위치를 비교합니다. 빨간 값은 그 지표에서 문제 쪽에 든 값입니다. **두 동네 Agent에게 비교 묻기** 로 Agent 에게 비교를 맡길 수 있고, **비교 끝내기** 로 한 동네 카드로 돌아갑니다.
- **바로 해 보기**: 시작 화면의 단추 네 개(말로 묻기, 자동 브리핑, 동네 진단 카드, 두 동네 비교)를 누르면 진단 화면으로 들어가 그 기능을 바로 엽니다. 동네 진단 카드와 두 동네 비교는 여러 지표에서 함께 걸린 동네를 골라 엽니다.
- **오른쪽 목록**: 위쪽 버튼으로 지표를 바꿉니다. 낙수 지수는 센터 데이터면 권역 단위, 관광공사 공개 데이터면 읍면동 단위로 보입니다. 쓰레기 부담은 행정동 단위, 도민 가게 몫은 시 단위로 보입니다.
- **위쪽 요약**: 제주 전체의 외국인 관광객 매출, 내국인 관광객 매출, 외국인 소비 비중입니다.

## 표시를 읽는 법

- **신뢰 낮음, 신뢰 보통**: 근거 이용자(또는 방문 인원)가 적다는 뜻입니다. 100 이상이면 표시하지 않고, 30 이상은 보통, 그보다 적으면 낮음입니다.
- **표본이 적어 비공개**: 근거가 10 미만이라 반출 기준에 따라 값을 보여주지 않습니다.
- **해당 없음(메움률)**: 내국인 관광객 소비가 줄지 않은 곳이라 메움률을 계산하지 않습니다.
- **기본 모드로 답합니다**: Claude 를 쓸 수 없어 정해진 규칙으로 답했습니다. 이유가 함께 표시됩니다.
- **계산 결과에서 확인되지 않은 수치**: 답변의 수치가 계산 결과에 없습니다. 인용하지 마세요.

## 꼭 알아둘 점

- 카드 데이터는 비씨카드 결제만 담습니다. 다른 카드, 현금, 중국 간편결제(알리페이·위챗페이)는 빠져 있어 외국인 소비는 실제보다 적게 잡힐 수 있습니다.
- 카드 데이터는 월 단위라 크루즈가 들어온 '날'의 효과를 직접 가르지 못합니다. 크루즈 기항 효과는 달 단위의 함께 움직임이며 인과가 아닙니다.
- 도민 가게 몫은 업종 안에서 매출이 매장 수에 비례한다고 가정한 추정입니다. 입도객 1인당 소비의 분모는 제주 전체 입도객이라 지역마다 같습니다.
- 답변은 분석 참고 자료이며 공식 통계가 아닙니다. 특정 국적의 관광객을 평가하는 자료가 아니라, 소비가 어디에 몰리고 어디가 비는지 보는 자료입니다.
- 프로그램을 닫으면 넣은 데이터가 사라집니다. 필요한 결과는 닫기 전에 보고서로 받으세요.
