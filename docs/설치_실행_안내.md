「제주 AI·빅데이터 활용 AI Agent 개발 챌린지」 제출작 (DataPlayLabs, 개인 참가)

외국인·크루즈 관광객은 늘었는데 그 소비가 제주 동네에 떨어지고 있는가 — "배는 오는데 돈은 안 온다"는 논쟁을 동네 단위 수치로 바꿔 주는 로컬 웹 프로그램입니다. 말로 물으면 외국인 소비 비중·낙수 지수·내국인 공백 메우기·크루즈 기항 효과·쓰레기 부담·입도객 1인당 소비·저녁·밤 소비·동네 식당 체감·도민 가게 몫·가게당 관광객 소비 등 지표 12종과 분석 알고리즘 3종(기대 대비 실제 소비, 크루즈 효과 보정, 동네 유형)을 계산해 근거와 함께 답하고, 문제가 겹치는 동네를 지도에 강조하며, 반출 가능한 보고서까지 만듭니다. 센터 PC 에서 실행하고 브라우저로 사용합니다.

> **프로그램에 실제 공개 데이터가 들어 있어, 센터 데이터 없이도 지표 8종이 실제 값으로 계산됩니다.** 제주관광공사 제주관광빅데이터플랫폼의 읍면동별 관광객 소비(BC카드, 2020.1~2026.9)와 방문객(SKT, 2019.1~2026.9), 관광객 입도통계(2023.1~2026.9), 크루즈 입항 실적(2023.3~2025.5), 소상공인 상가 매장 수(2026.9 기준)입니다. 센터에서 내려받은 CSV(카드·유동인구·종량제봉투·POS·매장 수)를 넣으면 그 데이터를 먼저 쓰고, 나머지 지표 4종도 계산됩니다. '가상 데이터 불러오기'는 센터 CSV 가 없을 때 12종을 모두 보여 주기 위한 시연용 난수입니다(`tools/make_mock_data.py`, 실제 통계 아님).

## 평가자·센터 담당자용 실행 안내

프로그래밍을 몰라도 아래 순서대로 하면 실행됩니다. 인터넷은 Claude 답변(`api.anthropic.com`)에만 쓰이고, 설치에는 필요 없습니다.

| 항목 | 내용 |
|---|---|
| 대상 PC | Windows 11 64비트 (센터 Agent 운영 PC: Intel Core i7-8700, GTX 1060, RAM 32GB) |
| 브라우저 | Chrome 또는 Edge, 해상도 1920×1080, 하드웨어 가속 사용 |
| 설치할 프로그램 | **Python 3.12 (64비트) 하나뿐** |
| 패키지 | `requirements.txt` 의 10개와 그 의존 패키지, 모두 37개. 버전은 `requirements.txt` 와 `wheels/` 파일 이름에 적혀 있고, 제출 폴더의 `wheels/` 에 들어 있어 내려받지 않습니다 |
| 실행 파일 | 제출 폴더 맨 위의 `run.bat` |
| 설정 파일 | 제출 폴더 맨 위의 `.env` (API 키. 아래 'API 키 설정') |
| 프로그램 본체 | `src\golmok\` (서버 `app.py`, Agent `agent.py`) |
| 설치되는 곳 | 제출 폴더 안의 `.venv\` 한 곳. 다른 곳에는 아무것도 쓰지 않습니다 |
| 개발·시험 환경 | macOS, Python 3.12.13, Chrome |

### 1. 설치 순서

1. 제출 zip 을 한글·공백이 없는 짧은 경로에 풉니다. 예: `C:\jeju-agent\`
2. [python.org](https://www.python.org/downloads/) 에서 **Python 3.12 (Windows installer 64-bit)** 를 받아 설치합니다. 설치 첫 화면 아래의 **Add python.exe to PATH** 를 꼭 선택합니다.
3. 푼 폴더의 `run.bat` 을 더블클릭합니다. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** 을 누릅니다.
4. 첫 실행은 `wheels\` 의 패키지를 `.venv\` 에 설치합니다. 2~5분 걸리며 인터넷이 필요 없습니다. (`wheels\` 가 없거나 설치에 실패하면 PyPI 에서 받습니다.)
5. 명령창에 `Starting.` 이 나오고 12초쯤 뒤 브라우저가 `http://localhost:8765` 를 엽니다. 열리지 않으면 Chrome 이나 Edge 주소창에 직접 입력합니다. 첫 실행은 글꼴 정보를 만드느라 1분쯤 더 걸릴 수 있습니다.

두 번째부터는 `run.bat` 만 더블클릭하면 바로 시작합니다. 명령창을 닫으면 프로그램이 끝나고, 넣은 데이터도 사라집니다.

### 2. 별도 권한이 필요한 항목: 서명 없는 확장 모듈

센터 PC 보안 정책이 디지털 서명 없는 확장 모듈(`.pyd`, `.dll`)을 막으면 `run.bat` 이 `ImportError` 나 "차단되었습니다" 메시지로 멈춥니다. 이 프로그램은 아래 11개 오픈소스 패키지의 확장 모듈 96개를 씁니다.

`duckdb`, `numpy`, `pandas`, `matplotlib`, `contourpy`, `kiwisolver`, `fonttools`, `pillow`, `pydantic_core`, `jiter`, `charset_normalizer`

- 폴더 단위로 허용 등록한다면 `<제출 폴더>\.venv\` 한 곳이면 됩니다.
- 파일 단위로 등록한다면 [확장 모듈 목록](확장모듈_목록.md)에 패키지·버전·파일 경로 96개를 모두 적어 두었습니다.
- 허용 등록 뒤 `run.bat` 을 다시 실행하면 됩니다. 설치를 처음부터 다시 하려면 `.venv` 폴더를 지우고 실행합니다.

### 3. 처음 실행해서 확인할 것 (5분)

1. 시작 화면에서 **진단 화면으로** 를 누릅니다. 프로그램에 든 실제 공개 데이터(2026년 9월)로 **주의 지역 종합** 이 바로 보입니다. CSV 를 넣지 않아도 됩니다.
2. 왼쪽 아래 질문창에 `우도면은 사람만 늘고 돈은 안 떨어지나요?` 를 넣고 **질문** 을 누릅니다. 20~40초 뒤 계획·실행·검증 단계와 답이 나오고, 섬과 오른쪽 목록이 바뀝니다. 답 아래 **보고서 내려받기 (PDF, 차트)** 로 zip 을 받습니다.
3. 오른쪽 위 지표 메뉴에서 **낙수 지수**, **기대 대비 실제** 등을 눌러 봅니다. 동네 이름을 누르면 그 동네로 확대되고, 왼쪽에 **동네 진단 카드** 가 열립니다. 카드의 **비교에 추가** 를 누르고 다른 동네를 누르면 두 동네를 나란히 비교합니다. 시작 화면의 **바로 해 보기** 단추 네 개로도 이 기능들을 바로 열 수 있습니다.
4. 센터 CSV 를 넣는 흐름은 왼쪽 위 **데이터 → 가상 데이터 불러오기** 로 볼 수 있습니다(1~2분). 센터 데이터 형식의 가상 CSV 9개가 `data\mock_center\` 에 만들어져 적재되고, 지표 12종이 모두 계산됩니다. 이 파일들을 **CSV 불러오기** 에 직접 끌어다 놓아도 됩니다. 가상 데이터의 수치는 실제 통계가 아닙니다.
5. 질문 없이 Agent 가 스스로 문제 동네를 찾는 **이번 달 자동 브리핑** 단추도 질문창 위에 있습니다(약 1분).

답 위에 "기본 모드로 답합니다"가 보이면 Claude 를 부르지 못한 것입니다. 표시된 이유(키 없음, 접속 차단 등)를 확인하세요. 기본 모드에서도 지표 계산·지도·보고서는 모두 동작합니다.

**Windows 11 에서 직접 실행해 보지는 못했습니다.** macOS 에서 같은 설치 방식(동봉 패키지로 새 가상환경 설치)과 제출 zip 을 새 폴더에 풀어 처음부터 실행하는 시험은 통과했습니다. `run.bat`, 맑은 고딕 PDF 출력, GTX 1060 에서의 3D 성능은 Windows 실기 확인이 필요합니다.

### 직접 실행 (macOS, Linux)

```bash
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env
.venv/bin/python -m uvicorn golmok.app:app --app-dir src --port 8765
```

## API 키 설정

키가 없어도 실행됩니다. 이때는 정해진 규칙으로 답하는 **기본 모드**로 동작합니다.

1. [Claude Console](https://platform.claude.com) 에서 API 키를 발급합니다. 사용량에 따라 요금이 청구됩니다.
2. 프로그램 폴더의 `.env` 파일을 메모장으로 엽니다. 없으면 `.env.example` 을 복사해 이름을 `.env` 로 바꿉니다.
3. `ANTHROPIC_API_KEY=` 뒤에 키를 붙여 넣고 저장합니다.
4. 프로그램을 다시 시작합니다.

<!-- EVAL_KEY -->이 제출본에는 API 키가 들어 있지 않습니다. 위 순서로 `.env` 에 키를 넣어야 Claude 답변을 볼 수 있습니다.<!-- /EVAL_KEY -->

- 키가 든 파일의 위치: 제출 폴더 맨 위의 `.env` (메모장으로 열 수 있는 글자 파일)
- 적용 방식: 프로그램이 시작할 때 `.env` 를 읽어 `ANTHROPIC_API_KEY` 환경변수로 씁니다. Windows 환경변수를 따로 설정할 필요가 없습니다. Windows 환경변수에 같은 이름이 이미 있으면 그 값을 먼저 씁니다.
- 실행 방법: `run.bat` 더블클릭. 키를 바꿨으면 명령창을 닫고 다시 실행합니다.
- 센터에 탑재한 뒤에는 센터 담당자가 `.env` 의 키를 센터 키로 바꿉니다. 키는 이용자 화면에 나타나지 않습니다.

| 환경변수 | 기본값 | 설명 |
|---|---|---|
| `ANTHROPIC_API_KEY` | 없음 | Claude API 키 |
| `GOLMOK_MODEL` | `claude-opus-5-5` | 사용할 모델 |
| `GOLMOK_EFFORT` | `medium` | 추론 강도 (`low`, `medium`, `high` 등) |
| `GOLMOK_OFFLINE` | 없음 | `1` 이면 키가 있어도 기본 모드로 동작 |

운영 비용을 볼 수 있도록 질문마다 토큰 사용량을 명령창에 표시합니다. 질문 내용은 남기지 않습니다.

## AI 활용

- Agent 실행: Claude API, Claude Opus 5.5 (`claude-opus-5-5`). 질문 이해, 계획, 도구 선택, 해석을 맡고, 계산과 수치 검증은 코드가 합니다.
- 개발: Claude Code (Claude Fable 5.1·5.2, Claude Opus 5.5) 로 조사, 설계, 코드·테스트·문서 작성을 했습니다. 주제 결정과 결과 검토는 참가자(1인)가 직접 했습니다.
- 자세한 내용은 [데이터 활용 명세 7절](데이터_활용_명세.md#7-ai-활용-내역)에 있습니다.

## 센터에서 처음 실행할 때

실제 센터 CSV 는 개발 PC 에서 시험할 수 없었습니다. 센터에서 CSV 를 처음 내려받으면 프로그램을 쓰기 전에 아래 점검을 돌려 주세요. 파일 식별, 숫자 컬럼, 지표가 쓰는 코드값(시간대, 매장주 구분, 권역), 데이터끼리 이어지는 비율, 지표 12종 계산 결과를 확인해 화면에만 출력합니다. 출력에는 원본 행이나 금액이 없습니다.

```bash
.venv\Scripts\python tools\center_check.py 내려받은CSV폴더
```

`[경고]`·`[오류]` 줄이 있으면 그 내용을 개발팀에 알려 주세요.

## 데이터 보존

- 넣은 CSV 는 적재 직후 지우고, 내용은 프로그램의 메모리에만 둡니다. 프로그램을 닫으면 사라집니다.
- 센터 PC 에 집계값을 따로 보존하지 않습니다.
- 외부 LLM 으로는 반출 기준을 통과한 응용집계만 보냅니다. CSV 원본은 보내지 않습니다.

## 폴더 구성

```
src/golmok/        프로그램 본체 (패키지 이름은 첫 설계 때의 '골목'을 그대로 둠)
  agent.py         Agent 루프(계획·실행·검증·고쳐 쓰기), 대화 기억, 자동 브리핑, 기본 모드 (Prompt 포함)
  tools.py         Agent 도구 7종 정의 (문제 동네 훑기, 추이, 두 달 비교, 동네 요약, 지표 계산, 데이터 확인·검색)
  metrics.py       낙수 진단 지표 12종 계산
  models.py        분석 알고리즘 3종 (회귀로 본 기대 대비 실제, 이중차분 크루즈 보정, k-평균 동네 유형)
  guard.py         반출 가드
  loader.py        센터 CSV 식별·적재
  report.py        PDF·PNG 보고서
  app.py           로컬 서버
  center_schemas.json  명세서에서 만든 센터 데이터 71종 스키마
  public_schemas.json  공개 데이터 5종(크루즈 입항 실적, 관광객 입도통계, 관광공사 소비·방문객, 상가 매장 수) 형식
  reference/       프로그램에 든 공개 데이터 (관광공사 소비 2020.1~2026.9·방문객 2019.1~2026.9, 크루즈 입항 실적 2023.3~2025.5, 관광객 입도통계 2023.1~2026.9, 상가 매장 수 2026.9 기준)
  static/          화면, 3D 장면, 지형, 소품
wheels/            Windows 64비트·Python 3.12용 패키지 37개 (오프라인 설치용, `pip download --platform win_amd64 --python-version 3.12` 로 받음)
tools/             스키마·지형·가상 데이터 생성, 공개 데이터 수집·정리(크루즈, 입도통계, 관광공사, 상가정보), 센터 CSV 점검, 평가셋 실행(eval_set.json, run_eval.py, eval_report.py), 제출 파일 제작 도구
tests/             자동 테스트 (100개)
docs/              매뉴얼과 명세
```

스키마와 지형은 생성 결과가 `src/golmok/` 에 포함되어 있어 다시 만들 필요가 없습니다. 다시 만들려면 공개된 명세서를 `data/center_spec/` 에, 고도 타일을 `data/terrain_tiles/` 에 넣고 `tools/` 의 스크립트를 실행합니다. 크루즈 입항 실적은 `python tools/fetch_cruise_arrivals.py`, 입도통계는 `python tools/fetch_foreign_arrivals.py` 로 다시 받을 수 있습니다(협회가 새 달을 게시하면 그 달까지 받습니다). 관광공사 소비·방문객은 제주관광빅데이터플랫폼에서 로그인해 '제주 지역별 소비'(regSn=27)와 '제주 지역별 방문객(읍면동)'(regSn=21)을 전체 기간으로 내려받은 뒤 `python tools/import_ijto.py 파일1 파일2` 로, 상가 매장 수는 공공데이터포털 '소상공인시장진흥공단_상가(상권)정보' zip 의 제주 CSV 를 `data/sangga_src/jeju/` 에 두고 `python tools/import_sangga.py` 로 바꿉니다.

개발용 시험과 도구 실행에는 `pyproject.toml` 의 `dev` 패키지가 필요합니다.

```bash
.venv/bin/pip install pytest openpyxl pillow scipy
.venv/bin/python -m pytest
```
