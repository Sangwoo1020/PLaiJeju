# 결과 설명자료

## 1. 문제 정의

제주 관광의 구조가 바뀌고 있는데, 늘어난 사람만큼 돈이 지역에 떨어지는지는 동네 단위로 아무도 답하지 못합니다.

- 내국인 관광객은 2026년 5월부터 여섯 달 연속 전년 대비 줄었습니다(10월 -12.9%). 외국인은 늘었고 그중 중국이 70%입니다. ([서울신문, 2026.10.27](https://www.seoul.co.kr/news/society/2026/10/27/20261027500064), [파이낸셜뉴스, 2026.11.9](https://www.fnnews.com/news/202611091108582110))
- 크루즈 관광객은 2023년 10만 명에서 2025년 75.6만 명, 2026년 80만 명 전망으로 늘었지만, 1인당 지출은 188달러에서 122달러로 줄었습니다. ([서울신문, 2026.1.20](https://www.seoul.co.kr/news/economy/2026/01/20/20260120500058), [네이트/연합, 2026.4.2](https://news.nate.com/view/20260402n39486))
- 2026년 10월 도의회 행정사무감사에서 "배는 오는데 돈은 안 온다", "소비가 대기업 면세점에 집중된다"는 지적과 함께 면세점 외 지역상권 카드소비 분석이 요구됐습니다. ([뉴스서울](https://newsseoul.co.kr/news/view/1065587439039128), [뉴스프리존](https://www.newsfreezone.co.kr/news/articleView.html?idxno=713312))
- 우도면은 2026년 8월 외국인 방문이 전년 동월 대비 257% 늘었습니다. ([제주관광빅데이터플랫폼](https://data.ijto.or.kr/bigdata/index.do), 2026.11.8 조회)

제주빅데이터센터의 카드 데이터는 이용자를 도민·내국인·중국·일본·동남아·기타외국으로 나눠 법정동·업종별로 갖고 있고, 단기체류 외국인 유동인구는 국적별로 행정동 단위로 있습니다. 둘을 겹치면 "사람은 왔는데 돈은 안 쓴 동네"를 셀 수 있습니다. 여기에 시간대별 카드, 외식업 POS, 매장주 구분 매장 수를 더하면 "머무는가", "동네 식당이 체감하는가", "도민 가게로 가는가"까지 볼 수 있고, 공개 입도통계를 분모로 쓰면 "입도객이 늘어난 만큼 돈도 늘었는가"를 볼 수 있습니다. 이 Agent 는 그 계산과 반출 기준 적용을 대신합니다. 센터 데이터가 없어도 제주관광공사가 공개한 읍면동별 관광객 소비(BC카드)·방문객(SKT)과 소상공인 상가 매장 수를 프로그램에 넣어 두어, 켜자마자 실제 값으로 동네를 진단합니다.

## 2. Agent 구조

```
이용자 질문 (앞선 대화 3개까지 기억)  /  자동 브리핑 (질문 없이 시작)
   │
Claude ─ 계획을 쓰고(화면에 '계획'), 볼 지표·동네·업종을 정하고, 결과를 보고 더 파고들지 판단
   │ 도구 호출
   ├ scan_issues      지표 10종을 동네별로 계산해 여러 지표에서 함께 걸린 동네 찾기
   ├ trend            동네의 월별 소비·방문객 전년 대비 추이
   ├ compare_periods  같은 지표를 두 달에 계산해 차이
   ├ place_summary    동네 요약 (외국인 소비·방문 변화, 낙수 지수, 가게당 소비)
   ├ compute_metric   낙수 지표 12종 + 분석 알고리즘 3종 계산 (코드가 계산)
   └ list_data · search_datasets  넣은 데이터 확인, 명세서·공개 데이터 형식 검색
          │
     반출 가드 ─ 표본 검사, 값 가림, 근거 컬럼 제거
          │
   수치 검증 ─ 답의 모든 % ·소수 수치를 계산 결과와 대조 → 근거 없으면 Claude 에게 되돌려 한 번 고쳐 쓰기
          │
   답변 + 화면 + 보고서
```

- 계산은 코드가, 판단과 설명은 Claude 가 맡습니다.
- 도구로 넘어가는 것은 가드를 통과한 표뿐이며, CSV 원본을 읽는 도구가 없습니다.
- 질문당 최대 8단계, 자동 브리핑은 14단계로 제한합니다.
- 답을 내기 전 코드가 수치를 검증하고, 근거 없는 수치는 Claude 에게 되돌려 고쳐 쓰게 합니다(1회). 검증 결과(확인한 수치 수)는 진행 단계에 보입니다.
- 이어지는 질문은 앞선 질문과 답(도구 결과는 빼고)을 함께 보내 맥락을 잇습니다. 대화는 메모리에만 두며 프로그램을 닫으면 사라집니다.
- Claude 를 쓸 수 없으면 기본 모드로 전환합니다.

| 지명 카드 | 첫 화면에서 지명·랜드마크를 누르면 그 동네의 외국인 소비·방문 변화, 낙수 지수, 가게당 소비, 2년 흐름을 공개 데이터로 보여 주고 진단 화면으로 이어 줌 |

## 4. 실행 결과

### 4-1. 실데이터 진단 (2026년 9월, 프로그램에 든 공개 데이터만)

센터 데이터와 가상 데이터 없이, 프로그램에 든 공개 데이터로 계산한 결과입니다. 소비는 BC카드 결제만 담아 현금·해외 간편결제가 빠지므로 규모가 아니라 방향으로 읽어야 합니다.

- **제주 전체**: 외국인 관광객 카드 소비 +24.7%, 내국인 관광객 −15.1%, 도민 +4.4%(전년 같은 달 대비). 외국인 소비 비중 13.8%(1년 전보다 +2.9%p). 관광객 전체 소비는 −6.7%로, 내국인이 줄어든 금액의 43.7%를 외국인 증가분이 메웠습니다.
- **1인당**: 외국인 입도객이 +16.1% 늘어 입도객 1인당 지역 카드 소비는 +7.4%였습니다. 반면 외국인 건당 결제액(객단가)은 −8.8%로, 결제는 잦아졌지만 한 번에 쓰는 돈은 줄었습니다.
- **낙수 지수(읍면동, 외국인)**: 낮은 곳은 추자면 0.01, 삼도1동 0.06, 오라동 0.07, 동홍동·서홍동 0.08로 외국인 방문에 비해 소비가 거의 닿지 않았습니다. 높은 곳은 이호동 6.03, 대륜동 3.50, 일도1동 3.03입니다. 방문객이 가장 많은 연동은 방문 비중 22.4%에 소비 비중 14.2%로 0.63, 중문동은 0.59였습니다. 우도면은 1.38, 성산읍은 2.16으로 평균보다 높았습니다.
- **가게당 관광객 소비(외국인)**: 가게 수에 비해 외국인 소비가 적은 곳은 추자면 0.01, 화북동 0.06, 한경면 0.07, 삼도1동 0.08이고, 몰리는 곳은 예래동 12.01, 이호동 9.60, 안덕면 3.30입니다.
- **크루즈 기항 효과(2023.3~2025.5, 외국인 전체)**: 중국발 크루즈 관광객이 많았던 달의 외국인 소비가 적었던 달보다 대부분 권역에서 26~40% 많았고, 서귀포시 동부만 −4.4%였습니다. 음식점(I56)만 보면 43~65%로 모든 권역에서 컸습니다. 이 기간은 외국인 관광 회복기라 뒤쪽 달일수록 크루즈와 소비가 함께 늘어, 효과가 부풀려졌을 수 있습니다.
- **기대 대비 실제 소비(외국인, 모든 업종)**: 기대보다 뚜렷하게 덜 쓴 동네는 봉개동(−56.8%)과 용담1동(−49.3%)입니다. 예측 오차의 90% 범위는 ±67%이고, 지난 6개월을 미리 예측해 본 오차는 중앙값 23.5%입니다.
- **크루즈 효과 보정(2023.3~2025.5)**: 섬 전체의 회복세를 빼면 크루즈가 많은 달에 섬 평균보다 더 늘어난 곳은 이호동(+146.8%)·외도동(+57.5%)·도두동(+48.1%)이고, 남원읍(−61.5%)·영천동(−33.5%)은 덜 늘었습니다. 보정 전 단순 비교에서 +5.3%였던 삼도2동은 보정 후 −25.0%로, 회복세가 효과처럼 보였던 사례입니다. 43곳 중 12곳이 '뚜렷함'입니다.
- **동네 유형(2025.10~2026.9)**: 쇼핑 소비형 10곳(원도심·시장 동네: 일도1·2동, 삼도2동, 중앙동 등), 숙박·리조트형 14곳(연동, 노형동, 중문동, 건입동 등), 사람만 오는형 10곳(외국인 소비 비중 중앙값 1.8%: 오라동, 동홍동, 대정읍 등), 음식·카페형 9곳(애월읍, 조천읍, 구좌읍, 성산읍, 우도면 등).
- **주의 지역 종합**(법정동 단위 요청 · 음식점·카페·주점 · 외국인 관광객): 여러 지표에서 함께 걸린 동네는 삼양동(지표 6개), 봉개동(5개), 삼도1동(5개)이었습니다.

기본 모드(규칙 기반 답변)와 화면·보고서로 확인했고, 아래 자동 브리핑은 실데이터로 Claude API 를 불러 시험했습니다.

### 4-2. 가상 데이터 시험

아래는 센터 데이터 형식으로 만든 **가상 데이터**로 실행한 결과입니다. 수치 자체에는 의미가 없고, 동작을 확인한 결과입니다.

**질문**: 외국인 관광객이 늘었는데 돈은 어느 동네에 떨어지나요? 크루즈 효과와 쓰레기 부담도 같이 봐 주세요 (2026-11-09, Claude Opus 5.5, 추론 강도 medium)

- Claude 가 도구를 7번 호출했습니다. 데이터를 확인한 뒤 소비 비중, 낙수 지수, 매출 증감률을 계산하고, 크루즈 기항 효과를 면세점과 음식점으로 나눠 두 번 계산한 다음 쓰레기 부담을 봤습니다.
- 결론을 "외국인 소비는 전역에서 늘었지만 돈은 제주시 중부(동)와 서귀포시 중부에 몰리고, 성산·우도 쪽은 사람에 비해 돈이 거의 떨어지지 않는다"로 요약했고, 낙수 지수(3.14 ~ 0.05)를 방문 비중과 소비 비중으로 풀어 설명했습니다.

**새 지표 실제 호출 시험** (가상 데이터, 2026-11-09, Claude Opus 5.5, 추론 강도 medium): "중국 관광객이 늘었는데 1인당 소비는 줄었나요? 크루즈 관광객이 낮에만 쓰고 떠나는지, 동네 식당과 도민 가게까지 돈이 가는지도 봐 주세요"

- 결론을 "중국 관광객 소비 총액은 늘었지만 입도객 한 사람당 소비와 건당 금액은 줄었고, 크루즈 효과는 면세점에서 가장 크며, 외국인 음식점 소비가 늘어난 지역에서도 동네 식당 가게당 매출은 줄었다"로 요약했습니다.

- 질문의 "크루즈 관광객이 낮에만 쓰는가"는 월 단위 데이터로 직접 가를 수 없다고 밝히고, 크루즈 효과가 큰 권역의 저녁·밤 비중으로 간접적으로만 답했습니다. 도민 가게 몫은 추정값이라는 점도 밝혔습니다.
- 수치 대조 경고 1건: 모델이 저녁·밤 비중을 "20~26%대"라는 범위로 뭉뚱그린 부분입니다. 계산 결과에 없는 값이라 표시된 것이며, 이후 프롬프트에 범위로 쓰지 말라는 지시와 영문 도구 이름을 쓰지 말라는 지시를 더했습니다.

**새 지표 기본 모드 시험** (가상 데이터, 2026년 10월): "크루즈 관광객 1인당 소비가 줄었나요? 동네 식당은 체감하나요? 저녁·밤에도 돈을 쓰나요? 도민 가게 몫은요?" → 기본 지표 5종에 더해 입도객 1인당 소비, 저녁·밤 소비, 동네 식당 체감, 도민 가게 몫을 계산했고 보고서 차트 9장이 만들어졌습니다. 화면 진단 11종 전체 계산은 0.8초 걸렸습니다(가게당 관광객 소비는 그 뒤에 추가). 우도면은 저녁·밤 비중 8.2%로 가장 낮게 나와, 가상 데이터에 심은 당일치기 모양이 드러났습니다.

**가상 데이터 복원 시험**: 가상 데이터에 심어 둔 모양이 지표에서 드러나는지 확인했습니다. 내국인 관광객 2026년 10월 -12.7% 설정 → 제주 전체 -10.3% 산출(권역·업종 표본 차이로 다소 완화됨). 우도면·성산읍에 심은 외국인 방문 급증 → 쓰레기 부담 지표의 외국인 방문 증감률 상위 2곳이 우도면(+145%)·성산읍(+90%). 항구 주변 중국 단체 소비를 크루즈 달에 연동 → 크루즈 기항 효과의 상관계수가 제주시 중부(동)·서귀포시 중부에서 가장 높음.

## 5. 검증 방법

| 검증 | 방법 | 결과 |
|---|---|---|
| 자동 테스트 | CSV 적재(공개 데이터 포함), 관광공사 원본 머리글 정리, 센터↔공개 소비 대체, 반출 가드, 지표 12종, Agent 루프, 기본 모드, 보고서, CP949·UTF-16 CSV, 오류가 나도 답이 나오는지, 장소 사진 라이선스, 로고·화면 단추 | 100개 통과 |

## 6. 한계

- **실제 센터 CSV 미검증**: 공개 데이터 5종은 실제 파일로 시험했지만, 센터 데이터는 명세서대로 만든 가상 데이터로 시험했습니다. 실제 파일의 값 형식이 다르면 수정이 필요할 수 있어, 센터에서 처음 돌릴 점검 도구(`tools/center_check.py`)를 함께 제출합니다.
- **Windows 미검증**: 개발은 macOS 에서 했습니다. `run.bat`, 맑은 고딕 PDF, GTX 1060 에서의 3D 성능은 확인하지 못했습니다. 센터 PC 보안 정책이 서명 없는 확장 모듈을 막으므로 11개 패키지(파일 96개)의 허용 등록이 필요하며, 목록을 `docs/확장모듈_목록.md` 에 적었습니다.
- **데이터 범위**: 비씨카드 결제만 담습니다. 중국 간편결제와 현금이 빠져 외국인 소비는 실제보다 적게 잡힐 수 있어 추이로 읽어야 합니다. 인과관계를 증명하지 않습니다.
- **월 단위**: 크루즈 입항일의 효과를 직접 가르지 못합니다. 크루즈 기항 효과는 달 단위의 함께 움직임이며, 계절·행사 영향이 섞입니다.
- **추정 지표**: 도민 가게 몫은 업종 안에서 매출이 매장 수에 비례한다고 가정합니다. 면세점처럼 법인 매장이 많은 업종의 실제 몫과 다를 수 있어 추이로 읽어야 합니다. 매장 수는 시 단위뿐입니다.
- **입도통계 범위**: 협회 확정치가 2026년 9월까지 게시되어 그 뒤 달은 이용자가 같은 형식으로 넣거나 수집 도구로 다시 받아야 합니다. 입도객은 제주 전체 값이라 입도객 1인당 소비는 지역마다 같은 분모를 씁니다.
- **크루즈 실데이터 범위**: 누리집 게시가 2025년 5월까지라 그 뒤 달은 이용자가 같은 형식으로 넣어야 합니다. 2023~2025년은 외국인 관광 회복기라 크루즈가 많은 달과 소비가 많은 달이 함께 뒤쪽에 몰려, 크루즈 기항 효과가 실제보다 크게 나올 수 있습니다.
- **관광공사 공개 데이터**: 소비는 BC카드 결제만이고 이용자가 도민·내국인 관광객·외국인 관광객 셋뿐이라 국적별로 볼 수 없으며, 크루즈 효과는 외국인 전체로 계산합니다. 소비 파일은 세부 구분이 빠진 채 조각으로 나뉘어 있어 합쳐 썼습니다. '제주시 동지역'을 센터 권역(중부 동·서)으로 나눈 것은 우리 기준입니다. 방문객은 SKT 이동통신 기준이며, 상세 페이지에 공공누리 유형이 표기되어 있지 않아 출처를 밝혀 비영리로 씁니다. 새 달은 플랫폼에 로그인해 직접 내려받아야 해 자동 연동하지 않았습니다.
- **가게당 관광객 소비**: 매장 수는 분기 한 시점(2026년 9월 말)의 영업 매장이라 과거 달과 비교하면 시점이 어긋납니다. 매장 크기와 업태를 구분하지 않고 한 곳으로 셉니다.
- **쓰레기 부담**: 종량제봉투에는 주민 배출이 섞여 있어 방문객 몫만 따로 보지 못합니다. 전년 대비 변화로 읽어야 합니다.
- **지역 단위**: 낙수 지수는 센터 데이터면 권역(7개)까지, 관광공사 공개 데이터면 읍면동(43개)까지 계산합니다. 쓰레기 부담은 행정동까지입니다. 주의 지역 종합은 행정동과 법정동 이름이 다른 동(화북동↔화북일동 등)을 따로 셉니다. 동네 위치는 대략 좌표입니다.
- **분석 알고리즘**: 기대 소비 모델은 방문객·계절·추세만 넣은 단순 회귀라 행사·날씨·환율 같은 요인은 담지 않으며, 미리 예측한 오차가 중앙값 20%대입니다. 크루즈 보정은 섬 평균 대비 '추가' 효과라 섬 전체에 고르게 퍼진 효과는 보이지 않습니다. 동네 유형의 이름은 묶음 평균의 두드러진 특징으로 붙인 것이라, 묶음 안에도 성격이 다른 동네가 섞일 수 있습니다.
- **기본 모드**: 정해진 단어를 찾는 방식이라 복잡한 질문은 제대로 풀지 못합니다.
- **설치**: Python 3.12 는 센터 담당자가 설치해야 합니다. 패키지는 `wheels/` 에 동봉해 인터넷 없이 설치되지만, Windows 에서 실제로 설치해 보지는 못했습니다.
- **응답 시간과 비용**: 질문마다 수십 초가 걸리고, 복잡한 질문일수록 비용이 늘어납니다.

## 7. 센터 활용 방안

- **행정 근거자료**: 도·시 관광 담당자가 "크루즈·외국인 소비가 어느 상권에 떨어졌는가"를 출처가 붙은 수치로 받아 행정사무감사 답변과 분산 정책 대상 선정에 씁니다.
- **의회·연구기관 탐색**: 용역 전에 권역별 낙수 지수와 메움률 추이를 확인합니다.
- **관광공사·업계**: 소비가 비는 동네와 접근성을 비교해 체류형·마을 관광 후보지를 찾습니다.
- **상권·소상공인**: 우리 동네에 외국인 소비가 늘었는지, 어느 업종인지 확인합니다.
- **반출 심사 부담 완화**: 처음부터 반출 기준에 맞춘 산출물과 출처·사유 초안을 만듭니다. 최종 심사는 센터가 합니다.
- **운영비**: 환경변수로 모델과 추론 강도를 바꿀 수 있고, 키가 없어도 기본 모드로 운영할 수 있습니다.
