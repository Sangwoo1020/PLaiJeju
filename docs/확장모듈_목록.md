# 확장 모듈 목록 (허용 등록용)

센터 PC 보안 정책(스마트 앱 컨트롤, AppLocker, WDAC 등)이 디지털 서명 없는 확장 모듈의 실행을 막으면 프로그램이 시작되지 않습니다. 아래는 `run.bat` 이 설치하는 패키지 가운데 확장 모듈(`.pyd`, `.dll`)이 든 패키지와 파일입니다. 모두 PyPI 에 공개된 오픈소스 패키지의 공식 배포 파일이며, `wheels/` 폴더에 그대로 들어 있습니다.

**폴더 단위로 등록할 때**: `<프로그램 폴더>\.venv\` 한 곳만 허용하면 됩니다(`run.bat` 첫 실행 뒤에 생깁니다).

**파일 단위로 등록할 때**: 아래 경로는 모두 `<프로그램 폴더>\.venv\Lib\site-packages\` 아래입니다.

Python 실행 파일(`python.exe`)은 python.org 가 서명해 배포한 설치 파일로 설치합니다.
